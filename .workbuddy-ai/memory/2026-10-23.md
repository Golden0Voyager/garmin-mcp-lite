## 排查：garmin-mcp-lite 在其他 MCP 客户端「服务起不来」

- 现象：用户在 Chatbox / opencode 里配置本 MCP，服务无法启动（不是工具调用报错）。
- 结论（按概率）：
  1. opencode 配置 schema 不同：顶层是 `mcp`（不是 `mcpServers`），必须 `type: "local"`，`command` 必须是**数组**；且 `timeout` 默认 5000ms，`uvx` 冷启动首次下载依赖必超时。
  2. Chatbox（Electron GUI）不继承 shell PATH → `uvx` ENOENT。需用绝对路径 `/Users/<user>/.local/bin/uvx`。
  3. 跨机器/跨客户端时 token 不在 `~/.garmin-mcp-lite/garmin_tokens.json`。
- 推荐统一方案：`uv tool install garmin-mcp-lite`，客户端直接指向 `~/.local/bin/garmin-mcp-lite` 绝对路径、无 args。规避 PATH + 冷启动超时两个问题。
- 本项目 README 目前只写了 Claude Desktop 的 `mcpServers` 格式，是这次踩坑的直接诱因。
- 环境限制：本沙箱内 `uv`/`uvx`/`pip install` 进程被 SIGKILL（rc=137），无法在此复现安装路径，只能静态审查 + 官方文档核对。
